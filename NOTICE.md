# Why CC0

A reporting standard nobody is allowed to copy is not a standard.

The spec, the JSON Schema, the validator and the examples in this repository
are released into the public domain under CC0 1.0. Take it, fork it, implement
it, extend it, sell something built on it. No attribution required, though it
is appreciated.

This is co-authored in the open with Utilia (@utiliax402). It moves to a
neutral repository the first time a third seller publishes a conforming file.
It should not belong to any one seller.
